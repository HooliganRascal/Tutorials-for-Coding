Programming catrgories:

> This book ends at page 1224

Computer languages deal with 2 concepts in general: **data** and **algorithm**
- Procesural programming: Emphasizes algorithms
- Object-oriented programming: Emphasizes the data
    - Class: What kind of data and how can they operate
    - Object: Specification of the concrete from a class
    - Bottom-up programming: from low-level class to high-level program
- Generic programming: Emphasizes the independence from a particular data type
